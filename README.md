## 📖 Sobre o Projeto

Este é um **quiz interativo** desenvolvido para auxiliar no estudo da disciplina **Ferramentas de Desenvolvimento Web**. O projeto foi criado com base no material de estudo da **Uninter** (aulas 1 a 6), oferecendo uma ferramenta prática para autoavaliação e revisão dos conceitos fundamentais de HTML, CSS, JavaScript, computação em nuvem e engenharia de software.

## 🎯 Finalidade

* **Uso Acadêmico:** complemento aos estudos da disciplina, permitindo que alunos testem seus conhecimentos de forma interativa.
* **Uso Pessoal:** ferramenta para revisão de conteúdos antes de provas e avaliações.
* **Recurso Didático:** material de apoio para professores e tutores da disciplina.

## ✨ Funcionalidades

## 🧠 Temas Discursivos

1. **HTML: Estrutura e Tags** – listas ordenadas/não ordenadas, tabelas, self closing tags
2. **CSS: Seletores e Estilização** – classes, id, pseudo-classes, cores e propriedades
3. **CSS: Float, Clear e CSS Grid** – controle de fluxo e layouts bidimensionais
4. **JavaScript: Métodos e Objetos** – push, unshift, pop, acesso a propriedades
5. **Engenharia de Software e Ciclo de Vida** – fases, crise do software, mitos e qualidade
