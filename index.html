1. HTML: Estrutura e Tags:
HTML (HyperText Markup Language) é uma linguagem de marcação utilizada para estruturar o conteúdo das páginas web. Não é uma linguagem de programação, pois não possui lógica condicional ou de repetição. As tags definem onde um comando começa e termina. As tags que não possuem fechamento são chamadas de self closing tags. Exemplos: <ul> para listas não ordenadas, <ol> para listas ordenadas, <li> para itens da lista, <table> para tabelas, <tr> para linhas de tabela. O navegador é o software responsável por interpretar o HTML e exibir a página ao usuário.

2. CSS: Seletores e Estilização:
CSS (Cascading Style Sheets) é a tecnologia padrão do HTML5 para gerar estilos. Enquanto o HTML dita "QUAIS" elementos estão na página, o CSS dita "COMO" eles serão apresentados.
• Seletores: por classe (ponto antes: .classe), por id (# antes), por tag (nome do elemento) e múltiplos seletores (separados por vírgula).
• Pseudo-classes: selecionam elementos em circunstâncias específicas (ex: a:link, a:hover). Sintaxe: seletor:pseudo-classe{ propriedade: valor; }.
• Propriedades principais: background-color (cor de fundo), font-family (fonte), font-style (itálico/oblíquo), color (cor do texto).
• Cores: podem ser escritas em inglês (blue, red, green) ou em hexadecimal/RGB (combinação de vermelho, verde e azul).

3. CSS: Float, Clear e CSS Grid:
• Float: retira o elemento do fluxo normal, permitindo que outros elementos o contornem lateralmente (esquerda ou direita).
• Clear: impede que um elemento seja posicionado ao lado de elementos flutuados anteriores, forçando-o a ser exibido abaixo deles.
• CSS Grid: ferramenta de layout bidimensional que permite controlar linhas e colunas. Um elemento se torna um contêiner grid quando sua propriedade display é definida como grid ou inline-grid. Permite posicionar elementos em células específicas, definir ordem e criar layouts responsivos sem a necessidade de floats. Exemplo: grid-template-columns: 100px 50px 80px 200px; define 4 colunas com larguras fixas.

4. JavaScript: Métodos e Objetos:
JavaScript é uma linguagem de programação que permite adicionar interatividade às páginas web.
• Métodos de array: push() adiciona item no final do array, unshift() adiciona no início, pop() remove o último item.
• Objetos: estruturas de dados conhecidas como registros, que armazenam vários valores de diferentes tipos em um só lugar. Cada campo tem nome (chave) e valor.
• Acesso a propriedades: pode ser feito com notação de ponto (exeObj.nr) ou com colchetes (exeObj["nr"]).
Exemplo: let exeObj = { nr: 500, str: "palavra" }; console.log(exeObj.nr);

5. Engenharia de Software e Ciclo de Vida:
A Engenharia de Software é uma disciplina de engenharia relacionada a todos os aspectos de produção de software, desde a especificação do sistema até a manutenção.
• Ciclo de vida genérico: três fases principais: definição (levantamento de requisitos e análise), desenvolvimento (codificação, testes) e manutenção (ajustes e modificações).
• Atividades estruturais: Especificação, Desenvolvimento, Validação e Evolução.
• Crise do software: expressão cunhada por Dijkstra (1971) para descrever problemas como projetos que estouram cronograma e orçamento, software de baixa qualidade e desenvolvimento informal.
• Mitos do software: classificados por Pressman em administrativos, do cliente e do profissional (ex: "assim que o programa for colocado em operação, nosso trabalho terminou" é um mito do profissional).
• Engenheiro de software: profissional que fornece ferramentas e processos aos desenvolvedores, garantindo que sejam aplicados de forma otimizada.
