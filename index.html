1. Design Responsivo vs Design Adaptativo:
Responsivo (RWD): um único layout fluido que se adapta automaticamente a qualquer tela usando grid fluído, imagens flexíveis e media queries.
Adaptativo (AWD): múltiplos layouts fixos, pré-definidos, carregados conforme o dispositivo detectado (desktop, tablet, smartphone).
Ambos usam media queries, mas o responsivo é contínuo e fluido; o adaptativo oferece mais controle, porém exige mais versões.

2. Heurísticas de Nielsen Aplicadas ao Design Móvel:
Diretrizes para avaliar usabilidade. Destaques para mobile:
• Visibilidade do status: mostrar onde o usuário está (indicadores, feedback).
• Correspondência com o mundo real: usar metáforas familiares (ex: carrinho de compras).
• Controle e liberdade: opções de desfazer/refazer.
• Prevenção de erros: alertar antes de ações críticas.
• Reconhecimento vs memorização: evitar que o usuário memorize atalhos.

3. Ferramentas de Prototipação:
• Balsamiq: wireframes de baixa fidelidade, rápidos e simples. Exporta PNG/PDF.
• Justinmind: protótipos avançados com gestos, animações e lógica condicional.
• Proto.io: protótipos interativos de alta fidelidade, testáveis no navegador ou via QR Code.
• UXPin: prototipagem baseada em código, colaborativa.
• Figma e Adobe XD: design e prototipagem interativa com colaboração.

4. Componentes do Material Design:
Sistema do Google para interfaces móveis. Componentes essenciais:
• App Bars: organizam título, navegação e ações principais.
• Botões: texto (baixa ênfase), contorno (média), contidos (alta) e alternância.
• Listas: organizam itens com texto, ícones e imagens.
• Campos de entrada: com estados visuais (focado, preenchido, erro).
• Checkbox: seleção múltipla; Radio Button: seleção única.

5. Mobile First e Design Centrado no Usuário:
Abordagem que prioriza a versão mobile no início do projeto (Luke Wroblewski, 2009).
Benefícios: foco no essencial, performance otimizada, experiência consistente do mobile para o desktop.
Google recomenda Mobile First como boa prática para projetos que buscam alcançar usuários móveis.
